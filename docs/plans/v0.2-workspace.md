# v0.2 Workspace & File Manager Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the v0.1 single-folder foundation into a multi-mount Workspace: users compose several existing local directories into one named Workspace (no file moves), manage per-mount read-write/read-only/excluded permissions and exclusion rules, perform safe create/rename/move/trash file operations, get live external-change propagation from a Rust `notify` watcher, and re-open recent Workspaces — all with Workspace config persisted in the OS AppData directory.

**Architecture:** Tauri 2 hosts a React + TypeScript + Vite frontend. All filesystem access stays behind the Rust boundary (v0.1 ADR 0001). Rust gains a `workspace` module (config/recent/permissions), a `filesystem::ops` module (create/rename/move/delete-to-trash), and a `watcher` module (per-mount `notify` watch, exclusion-filtered, 300 ms debounce, emitting create/remove/rename events to the frontend). The frontend keeps treating paths as opaque strings; Workspace state moves from single-root to multi-mount aggregated tree in the existing Zustand stores.

**Tech Stack (additions to v0.1):** Rust `notify` (file watcher), Rust `trash` (system Recycle Bin), `uuid` (workspace ids), `dirs` (AppData location). Frontend unchanged stack.

**Spec:** `docs/PROJECT_MASTER_SPEC.md` §6 (Workspace model), §6.2–6.4 (mount permissions, exclusions, config location), §7 (File View), §7.1 (trash), §13 (unchanged), §44 (schema versioning). Design: `docs/specs/2026-08-27-v0.2-workspace-design.md`.

## Global Constraints

- Local files are the source of truth; Markdown/TeX must remain open, portable formats.
- All filesystem access passes through Rust commands/services; React must not read/write arbitrary paths directly.
- No silent overwrites, no silent reformatting, no silent data loss. Rename/move does NOT rewrite links in v0.2 (no link index; documented in release notes).
- Delete goes to the OS Recycle Bin by default (Rust `trash` crate); permanent delete is a separate, double-confirmed action (not in v0.2 scope).
- Workspace config lives in `<AppData>/<app>/workspaces/<id>.json` (spec §6.4), NOT in user knowledge directories. No SQLite in v0.2 (v0.7).
- Default exclusion set (spec §6.3): `.git`, `node_modules`, `dist`, `build`, `target`, `.venv`, `venv`, `.cache`, `coverage`. Must remain a superset of v0.1's five hardcoded ignores (`.git, node_modules, dist, build, target`) — no scanner regression.
- Each mount supports read-write / read-only / excluded. Read-only mounts refuse mutations in the UI AND in Rust (three-layer defense: UI disable + Rust `PermissionDenied` + tree marker).
- `excluded` mounts: not indexed, not watched, not in the tree.
- Watcher: one per mount, follows exclusion rules, 300 ms debounce, coexists with the manual Refresh button (Refresh = forced full rescan).
- Moving/renaming an open document follows it to its new path (rename event); deleting it puts the editor into the existing "file missing on disk" state.
- Workspace schema is versioned (spec §44); migration: detect old version → back up → migrate → validate → switch.
- TypeScript strict mode. Rust must not `unwrap()` user-controlled filesystem data.
- `pnpm verify` must pass with fresh output before any completion claim; manual Windows 11 smoke before tagging `v0.2.0-alpha`.
- Move is same-mount only in v0.2 (no cross-mount, no drag & drop). Cut/paste move within a single mount only.
- No test touches real user directories (spec §32.2); tests use `tempfile`.

```rust
use std::fs;
use std::path::{Path, PathBuf};

use crate::errors::AppError;
use serde::{Deserialize, Serialize};

pub const DEFAULT_EXCLUSIONS: [&str; 9] = [".git", "node_modules", "dist", "build", "target", ".venv", "venv", ".cache", "coverage"];

pub const WORKSPACE_SCHEMA_VERSION: u32 = 1;

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct WorkspaceConfig {
    pub schema_version: u32,
    pub id: String,
    pub name: String,
    pub mounts: Vec<MountConfig>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct MountConfig {
    pub path: String,
    pub permission: MountPermission,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub exclusions: Option<Vec<String>>,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "kebab-case")]
pub enum MountPermission {
    ReadWrite,
    ReadOnly,
    Excluded,
}

pub fn default_exclusions() -> Vec<String> {
    DEFAULT_EXCLUSIONS.iter().map(|s| s.to_string()).collect()
}

fn app_workspace_root(app_data_dir: &Path) -> Result<PathBuf, AppError> {
    Ok(app_data_dir.join("workspaces"))
}

pub fn workspace_dir(app_data_dir: &Path) -> Result<PathBuf, AppError> {
    let dir = app_workspace_root(app_data_dir)?;
    fs::create_dir_all(&dir).map_err(|e| io_error(e, &dir))?;
    Ok(dir)
}

pub fn workspace_file_path(app_data_dir: &Path, id: &str) -> Result<PathBuf, AppError> {
    Ok(workspace_dir(app_data_dir)?.join(format!("{id}.json")))
}

pub fn load_workspace(app_data_dir: &Path, id: &str) -> Result<WorkspaceConfig, AppError> {
    let path = workspace_file_path(app_data_dir, id)?;
    let bytes = match fs::read(&path) {
        Ok(b) => b,
        Err(e) if e.kind() == std::io::ErrorKind::NotFound => {
            return Err(AppError::WorkspaceNotFound { id: id.to_string() });
        }
        Err(e) => return Err(io_error(e, &path)),
    };
    serde_json::from_slice(&bytes).map_err(|_| AppError::InvalidWorkspaceConfig { id: id.to_string() })
}

pub fn save_workspace(app_data_dir: &Path, config: &WorkspaceConfig) -> Result<(), AppError> {
    let dir = workspace_dir(app_data_dir)?;
    let final_path = dir.join(format!("{}.json", config.id));
    let bytes = serde_json::to_vec_pretty(config).map_err(|e| AppError::Io { message: e.to_string() })?;
    let tmp_path = dir.join(format!("{}.tmp-{}", config.id, std::process::id()));
    fs::write(&tmp_path, &bytes).map_err(|e| io_error(e, &tmp_path))?;
    // Reuse the atomic replace semantics verified in v0.1's writer.
    fs::rename(&tmp_path, &final_path).map_err(|e| {
        let _ = fs::remove_file(&tmp_path);
        io_error(e, &final_path)
    })?;
    Ok(())
}

pub fn create_workspace(app_data_dir: &Path, name: &str) -> Result<WorkspaceConfig, AppError> {
    let config = WorkspaceConfig {
        schema_version: WORKSPACE_SCHEMA_VERSION,
        id: uuid::Uuid::new_v4().to_string(),
        name: name.to_string(),
        mounts: Vec::new(),
        exclusions: default_exclusions(),
    };
    save_workspace(app_data_dir, &config)?;
    Ok(config)
}

pub fn effective_exclusions(config: &WorkspaceConfig, mount: &MountConfig) -> Vec<String> {
    mount.exclusions.clone().unwrap_or_else(|| {
        if config.exclusions.is_empty() {
            default_exclusions()
        } else {
            config.exclusions.clone()
        }
    })
}

pub fn list_workspaces(app_data_dir: &Path) -> Result<Vec<WorkspaceConfig>, AppError> {
    let dir = workspace_dir(app_data_dir)?;
    let mut out = Vec::new();
    for entry in fs::read_dir(&dir).map_err(|e| io_error(e, &dir))? {
        let entry = entry.map_err(|e| io_error(e, &dir))?;
        if entry.path().extension().and_then(|e| e.to_str()) == Some("json") {
            let id = entry.file_name().to_string_lossy().replace(".json", "");
            if let Ok(cfg) = load_workspace(app_data_dir, &id) {
                out.push(cfg);
            }
        }
    }
    out.sort_by(|a, b| a.name.cmp(&b.name));
    Ok(out)
}

fn io_error(e: std::io::Error, path: &Path) -> AppError {
    match e.kind() {
        std::io::ErrorKind::NotFound => AppError::FileNotFound { path: path.to_string_lossy().into_owned() },
        std::io::ErrorKind::PermissionDenied => AppError::PermissionDenied { path: path.to_string_lossy().into_owned() },
        _ => AppError::Io { message: e.to_string() },
    }
}
```

Note: `app_data_dir` is passed in (the caller resolves it via `dirs::data_dir()`), keeping config logic testable with tempfile and free of hardcoded system paths.

```rust
use std::fs;
use std::path::Path;

use crate::errors::AppError;

const MAX_RECENT: usize = 8;

fn recent_file(app_data_dir: &Path) -> Result<std::path::PathBuf, AppError> {
    let dir = app_data_dir.join("workspaces");
    fs::create_dir_all(&dir).map_err(|e| AppError::Io { message: e.to_string() })?;
    Ok(dir.join("recent.json"))
}

pub fn push_recent(app_data_dir: &Path, id: &str) -> Result<(), AppError> {
    let mut recent = load_recent(app_data_dir)?;
    recent.retain(|x| x != id);
    recent.insert(0, id.to_string());
    recent.truncate(MAX_RECENT);
    let path = recent_file(app_data_dir)?;
    let bytes = serde_json::to_vec_pretty(&recent).map_err(|e| AppError::Io { message: e.to_string() })?;
    let tmp = path.with_extension(format!("tmp-{}", std::process::id()));
    fs::write(&tmp, &bytes).map_err(|e| AppError::Io { message: e.to_string() })?;
    fs::rename(&tmp, &path).map_err(|e| {
        let _ = fs::remove_file(&tmp);
        AppError::Io { message: e.to_string() }
    })?;
    Ok(())
}

pub fn load_recent(app_data_dir: &Path) -> Result<Vec<String>, AppError> {
    let path = recent_file(app_data_dir)?;
    if !path.exists() {
        return Ok(Vec::new());
    }
    let bytes = fs::read(&path).map_err(|e| AppError::Io { message: e.to_string() })?;
    Ok(serde_json::from_slice(&bytes).unwrap_or_default())
}
```

# v0.2 Acceptance Criteria

- [ ] A user can compose multiple existing local directories into one named Workspace without moving files.
- [ ] Mounts support read-write / read-only / excluded; read-only mounts refuse file operations in the UI AND in Rust (PermissionDenied).
- [ ] New folder, new Markdown, rename, delete-to-system-Trash, and same-mount cut/paste move work against real files.
- [ ] Deleted files land in the OS Recycle Bin.
- [ ] Default exclusions (§6.3) apply; users can view/edit per-mount exclusions.
- [ ] External file changes appear in the tree live (watcher) and via manual Refresh; watcher honors exclusions.
- [ ] Renaming/moving an open document follows it to the new path; deleting it shows the missing-file state.
- [ ] Recent workspaces persist and one-click reopen.
- [ ] Workspace config persists in AppData JSON (never in user knowledge dirs); corrupt/old-schema config fails safely.
- [ ] `pnpm verify` passes with fresh output.
